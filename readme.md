## Sobre o projeto
Projeto feito em node.js com foco na criação de chamados  na versão 0.1.0 

## Funcionalidade
Versão 0.1.0 permite:
Criação de chamados no terminal;
Listar chamados existente;
Buscar chamado por id;
Deletar um chamado por id;
Atualizar o status de um chamado;
Salvar chamadados em json em um arquivo local;

## Tecnologias utilizadas
Node.js

## Pré-requisitos
Node.js versão 24.10
Baixar as dependências do projeto usando o comando
"npm install"

## Como executar o projeto
Digitar node index.js na raiz do projeto para iniciliazar o sistema
